# 🍔 Food Ordering Website

A complete food ordering web application built with **React.js**.  
The website allows users to browse food items, add them to a shopping cart, and complete registration/login to place orders.

---

## 🚀 Features

- 🏠 Home page with featured food items
- 📦 Shopping Cart (Add / Remove / Update items)
- 🔐 User Authentication (Register & Login)
- 📱 Responsive Design (works on mobile & desktop)
- ⚡ Fast and optimized using **Vite + React**

---

## 🛠️ Tech Stack

- **Frontend:** React.js, React Router
- **State Management:** React Context API
- **Styling:** CSS
- **Build Tool:** Vite
